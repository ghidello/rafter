# Rafter by Sotsera

Structural support for .NET automation scripts.

Rafter is being designed from its public experience inward. The proposed library-only syntax is maintained in the
[example portfolio](examples/README.md) before implementation begins.

The agreed implementation sequence and acceptance criteria are recorded in the
[implementation plan](docs/implementation-plan.md).

## Building

Rafter currently requires the .NET 10 SDK selected by `global.json` and PowerShell 7. The supported Phase 1 build
hosts are Windows x64, Linux x64, and macOS x64. See the [development guide](docs/development.md) for the complete
local verification sequence and project ownership map.
